## 完整声明核对

对象固定为：

- m:ℕ，1≤m；H(m)=(m:ℝ)+1，u(m)=π/(4H(m))。
- a(m)=H(m)⁻¹·(Real.cos(u(m))/Real.sin(u(m)))。
- rho(m)=Real.cos(π/(2H(m)))，λ=π²/8。
- h:ℝ，(m:ℝ)≤h<(m:ℝ)+1；δ(m,h)=H(m)−h。
- n:ℕ，包括0，实际表达式使用实数强制转换 (n:ℝ)。

∃ C:ℝ, 0<C ∧
  ∀ m:ℕ, 1≤m →
  ∀ h:ℝ, (m:ℝ)≤h → h<(m:ℝ)+1 →
  ∀ n:ℕ,
    | (π²/8)·(n:ℝ)/h²
      + (n:ℝ)·Real.log(rho(m))
      + Real.log(π·a(m)/4)
      − (π²/4)·((n:ℝ)/h³)·(H(m)−h) |
    ≤ C·((n:ℝ)/h⁴ + 1/H(m)²)。

这里 C 先于全部 m、h、n 选定，且不依赖这些参数、由它们决定的 δ、任何序列或 S4 的有界性常数 M。没有额外 H0、充分大、正 n、奇偶或尺度前提。自然语言第61–67行与显式量词第71–79行表达同一结论。
