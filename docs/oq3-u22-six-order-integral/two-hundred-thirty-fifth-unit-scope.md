# EX235 exact six-order finite polynomial coefficients

Two public declarations frozen before implementation. The first derives the
cutoff word recurrence by splitting an actual word into its head and tail,
including the empty-word value. The second identifies the literal EU/EV/EW
filtered polynomial with the six displayed Bell coefficient rows, for arbitrary
complex coefficients and arbitrary complex scale t. Every multiplicity and
factorial comes from the actual finite-word sum; no coefficient identity is
assumed. Eight statement lets in the second declaration and one in the first
are part of the frozen interface. No new definition or VALUE is planned.

This is finite algebra only. The actual canonical coefficients are still the
true scalar-CGF derivatives already fixed in EW234. Their later explicit
coefficient-table consumer must instantiate the same law, same E and same
actual IID rho and prove the normalization algebra. This unit neither adds an
analytic premise nor proves an exponential/Fourier/inversion bound.
