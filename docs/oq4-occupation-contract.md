# O0/OC 到有限边界层支付的积分接口冻结 v1

源 current/oq4/b01/proof01.md §5 OC、§6 R5。只关闭有限层积分比较；不把未证O0、R3或长时间K改名当输入后宣称根闭合。

设(Ω,μ)为有限测度空间，d:Ω→ℝ可测，F:Ω→ℝ可积，L:ℕ，C≥0，a:ℕ→ℝ在j<L时非负。设μ-几乎处处0≤d(ω)<L。定义闭开层

E_j={ω | (j:ℝ)≤d(ω) 且 d(ω)<(j:ℝ)+1}。

前提：
1. μ-几乎处处，对每个j<L，若ω∈E_j，则F(ω)≤a_j。
2. 每个j<L都有 μ.real(E_j)≤C(j+1)。

结论：∫F dμ≤C sum_{j<L}(j+1)a_j。

L=0、μ=0、d整数值、层上有原子均包括；d的约束只在几乎处处集合上。上端点d=h按j=floor(h)归层，取L=floor(h)+1可覆盖全部0≤d≤h，不能遗漏整数h。每个层左闭右开，不需要层无原子。

这是有限测度分层积分不等式，不包含概率生存或区间集中结论。源应用C=C_M/h²，a_j取边界缺陷在层内的上界；再与已证R6的期望支付相接。若应用使用带能量权重的有限测度，需要另证权重可积及O2，本单元不供应它们。F无需非负是合法的局部推广，不削弱源调用。

拟模块 Shao/OQ4/OccupationPayment.lean。不得增加全局d有界的逐点前提（冻结仅a.e.）、F有界、无原子、密度或隐藏的长时间核结论。冻结后作者不得改前提。
