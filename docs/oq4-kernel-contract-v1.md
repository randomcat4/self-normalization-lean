# OQ4 单步被杀核对象与积分接口冻结 v1

源 current/oq4/b01/proof01.md §1 K_h定义、§6 R1。使用Mathlib真正的可测Kernel对象，不把K/Kv主定理或层占据概率作为构造输入。

ν为ℝ的Borel概率测度，h为任意实数。在ℝ上定义一步核P_h，使对每个起点z，其行测度精确为

P_h(z)=((y↦z+y)_*ν).restrict([-h,h])。

源只使用|z|≤h的起点；在整个ℝ上的上述延拓只为使用标准Kernel类型，源域内数学含义不变。目标区间闭、严格离开才被杀，h=0的原子仍可保留；不得把行归一化为概率测度。

冻结结论：
1. 实际构造Mathlib的Kernel ℝ ℝ（因而逐可测集合对z可测），证明上述逐行测度恒等式。
2. 每行总质量≤1，并具有统一有限核界；每行κ-a.e.输出|w|≤h。
3. 任意有界Borel实函数f，对所有z有
   ∫f(w)dP_h(z)(w)=∫[若|z+y|≤h则f(z+y)，否则0]dν(y)。
   应显式给出两侧可积性，不能借不可积积分默认0证明。
4. 对每个实a，余弦测试的积分精确等于已审Kcos(ν,a,h,z)。

ν无需中心、非零方差或矩；支持可无界，可有原子。不得新增密度、非格点、第四矩等。f的有界Borel接口覆盖源中的1、余弦及已证有界残差；不宣称任意不可积f上的线性。
