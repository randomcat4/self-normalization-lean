# 端点分布函数到初始期望误差

来源 main.tex 1038–1076（cn:initial）：bounded variation 的期望误差传递、闭阈值及其原子处理。本模块在真实已接受的桥完成函数上给出更直接的等价机制：上完成概率u与上完成减区间完成的缺额d都是[0,1]中的反单调函数，初始g=u-d。闭阈值截断后两者仍反单调且在[0,1]，因此边际和闭阈值联合期望差均≤2δ。

完整声明先冻结再实现，六头含二私有。先用sSup分类实数下集为empty/univ/Iio/Iic；闭CDF误差通过递增Iic(x-1/(n+1))的真实测度连续性推广到Iio。对任意有界反单调f，层积分公式把期望写成t∈(0,1]上超水平下集的概率积分，各概率差≤δ，控制期望差≤δ。所有积分先证明可测可积，不利用默认不可积积分值。两反单调分量差的三角不等式给出2δ；闭mask在v点不换成开mask，无需无原子假设，μ和ρ是任意明确的概率律。
