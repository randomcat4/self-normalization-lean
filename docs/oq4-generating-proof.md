# S2–S3 与生成函数系数提取：匿名完整推导

仅设 L≥1、C≥0，且每个 k≥1 都有 0≤A_k≤1 与 A_k≥1/2−CL/√k。设 0<s<1。

## 真正的和式与 S2

W=Σ_{k≥1}s^k A_k/k 的每项非负且至多 s^k，故由几何级数比较真正绝对可和。对数幂级数 Σ_{k≥1}s^k/k=−log(1−s) 也是真正可和。

设 J=⌊L²⌋≥1，D_k=s^k(1/2−A_k)/k。D 是上述两个可和级数的差，故可和。对于1≤k≤J，由 A_k≥0、s^k≤1，D_k≤1/(2k)。对于k≥J+1，由 S1 下界和 C≥0，D_k≤CL/k^{3/2}。于是
ΣD_k≤(1/2)H_J+CL Σ_{k≥J+1}k^{-3/2}。
此处不依赖未缓存的积分比较模块。由实数对数不等式1−r⁻¹≤log r，代入r=(x+1)/x可得1/(x+1)≤log(x+1)−log x；归纳相加给H_J≤1+logJ≤1+log(L²)=1+2logL。

幂尾的真可和性直接由有限望远镜建立。若a=√x、b=√(x+1)，则0<a≤b、(a+b)(b−a)=1，且a(a+b)≤2b²。乘b−a≥0并化简即得
1/((x+1)√(x+1))≤2(a⁻¹−b⁻¹)。
代x=J+n并对0≤n<N相加，得尾前缀≤2(1/√J−1/√(N+J))≤2/√J。各项非负，故由部分和有界判据，该尾级数真正Summable，并由部分和极限保持≤2/√J。此证明包括J=1，且从k=J+1起估计尾和。

由 J≤L²<J+1、J≥1 得 L²<2J，进而2L/√J≤3。所有根号和分母均正。因此
ΣD_k≤logL+1/2+3C≤logL+1+3C。
由于 W=(1/2)[−log(1−s)]−ΣD_k，便得冻结 S2：
W≥−(1/2)log(1−s)−logL−(1+3C)。
没有把 J 当作额外输入；L=1 时 J=1、初段和正常保留。

## 真正的 G 与 S3

另设所有j≥0均有0≤a_j≤1，且a非增。G(s)=Σ_{j≥0}s^j a_j 由几何级数比较真正绝对可和，a_0 完整保留。此处明确假设每个0<s<1都满足精确 SP 型恒等式 G(s)=(1−s)⁻¹exp(−W(s))，并不证明该恒等式。

由 S2 和指数单调性，exp(−W)≤exp(1+3C)L√(1−s)；L>0、1−s>0，故
G(s)≤exp(1+3C)L/√(1−s)。

## m≥1 的系数界

固定自然 m≥1，取 s=exp(−1/m)。因 m>0，0<s<1，且 s^m=exp(−1)。记 x=1/m∈(0,1]。由1+x≤exp x得exp(−x)≤1/(1+x)≤1−x/2，故1−s≥1/(2m)。因此1/√(1−s)≤√(2m)。

真正G中每项非负，故含 j=0 的有限前缀满足
G≥Σ_{j=0}^{m−1}s^j a_j≥m s^m a_m=m exp(−1)a_m。
第二步仅使用j<m⇒j≤m、a_j≥a_m、0<s<1⇒s^j≥s^m，以及a_m≥0。没有丢弃 a_0，也没有将零项当作可除分母。

再用 S3，除以正m并乘exp1，得到
a_m≤exp1·G/m≤exp(2+3C)L√(2m)/m
=√2 exp(2+3C)L/√m。
全部步骤在m=1、L=1、C=0时成立。
