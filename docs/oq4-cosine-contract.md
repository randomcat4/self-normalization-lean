# R0 自由一步三角系数的三阶矩界冻结 v1

源 current/oq4/b01/proof01.md §6 R0：ρ_h=Ecos(a_hY)、η_h=Esin(a_hY)，a_h=π/(2h)。本单元关闭其普通Taylor期望输入，不假设ρ是杀死核特征值。

设 (Ω,μ) 为概率空间，Y:Ω→ℝ，Y、Y²、|Y|³ 可积，∫Y=0、∫Y²=1。令 β=∫|Y|³。对每个实数 a（含0、负值及任意大值）定义 ρ(a)=∫cos(aY)、η(a)=∫sin(aY)。精确结论：

|ρ(a)−(1−a²/2)|≤|a|³ β/6，
|η(a)|≤|a|³ β/6。

允许先关闭逐点全局标量界 |cos(t)−(1−t²/2)|≤|t|³/6 和 |sin(t)−t|≤|t|³/6，然后积分。不得加入Y有界、第四矩、对称性、指数矩或密度。概率空间可有原子。

对 a_h=π/(2h)、h>0，可再提供精确代入版本：
|ρ_h−(1−π²/(8h²))|≤π³ β/(48h³)，|η_h|≤π³ β/(48h³)。
它们给出源R0所需O_M(h^(-3))，但本单元不主张最终0<ρ<1、R1/R2、R3、K/Kv或完整OQ4。
