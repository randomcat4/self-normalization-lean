## 1. 外部正弦界的实际作用域


第一项没有 `|x|≤1`、`x≥0` 或其他大小前提。用 `|s-t|=|t-s|` 即得匿名证明要求的 `|sin t-t|≤|t|³/6`，对零、负数和任意大实数均有效。第二项只要求 `x≥0`，恰好由后续 `u∈[0,3]` 供应；第三项对实参数没有额外范围限制。没有把小角度定理误用为全局定理。

## 2. 余弦全局三阶界及分段单调性

匿名证明第 13–35 行完整且非循环。

1. 对 `x≥0` 定义 `E(x)=cos x-(1-x²/2)`。由上面实际全局余弦下界，`E(x)≥0`，故其绝对值确可去掉。
2. 当 `x≥3`，`cos x≤1` 给出 `E(x)≤x²/2`，而 `x²(x-3)≥0` 正好等价于 `x²/2≤x³/6`。这一步包括 `x=3`，也没有需要再限制 `x` 的三角函数符号。
3. 当 `0≤x≤3`，取 `F(u)=u³/6-E(u)`，求导确得 `F'(u)=u²/2+sin u-u`。在整个 `0≤u≤3` 上，`sin_ge_sub_cube` 给出

   `F'(u) ≥ u²/2-u³/6 = u²(3-u)/6 ≥ 0`。

   三角函数和多项式使 `F` 在 `[0,3]` 连续、在内部可微，所以导数非负判据确能推出闭区间单调不减。`F(0)=0`，因而 `F(x)≥0`。这里不需要导数严格为正，端点 `u=0,3` 的零因子没有被排除。
4. `x=0` 和 `x=3` 均由上述闭区间或大参数分支覆盖。对于负 `t`，取 `x=-t=|t|`，用余弦偶性及平方不变，把结论转回 `|cos t-(1-t²/2)|≤|t|³/6`。全部实数范围因此闭合。

证明没有积分第四阶余项，没有引入第四矩。所用下界与目标三阶上界不是彼此依赖的循环论证。

## 3. 可积性与概率积分不等式

冻结第 5–10 行的全部假设均在匿名证明第 39–69 行保留。

1. `Y`、`Y²`、`|Y|³` 三项可积性分别显式假设，`μ` 为概率测度，`∫Y=0`、`∫Y²=1`。可积性使 `Y` 几乎处处强可测；乘固定实数 `a`、再复合连续的正弦或余弦，仍几乎处处强可测。二者绝对值均不超过可积常数 `1`，所以都可积。这不需要全局可测代表元、无原子性、密度或支持有界性。
2. `P=1-(a²/2)Y²` 可积，因为概率测度使常数 `1` 可积，且 `Y²` 可积；`aY` 同样可积。概率归一化和矩假设正确给出 `∫P=1-a²/2` 及 `∫aY=0`。因此两个余项本身均可积，且其积分精确等于所求的余弦差和正弦系数，没有跳过积分加减的可积条件。
3. 点态代入 `t=aY` 合法，因为标量界适用于全部实数。`(aY)²=a²Y²`，`|aY|³=|a|³|Y|³`，因此两个余项的绝对值均受同一非负函数 `(|a|³/6)|Y|³` 控制。该函数由第三绝对矩假设可积；余项绝对值也由其已证可积性而可积。
4. 实积分三角不等式和单调性给出

   `|∫r| ≤ ∫|r| ≤ ∫((|a|³/6)|Y|³) = |a|³β/6`，

   其中 `β=∫|Y|³` 是有限且非负的实数。这正是冻结的两条结论，不需要以不可积函数的默认积分代替实际积分，也不需要交换任何无限过程。
5. 当 `a=0`，概率归一化给 `ρ(0)=1`、`η(0)=0`，两侧误差均零。负 `a` 由 `|a|³` 正确处理，任意大的 `a` 没有被截断。允许原子及无界 `Y`，没有额外的对称性、指数矩或第四矩条件。

## 4. h 代入及数值常数

匿名证明第 73–83 行正确对应冻结第 12–14 行。由 `h>0` 和 `π>0` 得 `a_h=π/(2h)>0`，所有分母非零，且

```text
a_h²/2 = π²/(8h²),
```
