# OQ4 杀死核递推与精确归一化冻结 v1

源 current/oq4/b01/proof01.md §8 D0–D4。建立真实有限核作用到已审有限标量递推之间的代数桥。依赖已冻结KilledIteration的真实可积半群、正性与线性；R3/R4的块估计明确保留为条件，不把它们当成已证概率事实。

ν任意ℝ Borel概率测度，h>0，a=π/(2h)，φ(w)=cos(aw)，ρ=∫cos(ay)dν(y)。P为已审闭区间杀死核，U_n为P^n的真实积分作用。r(w)=Kcos(ν,a,h,w)−ρφ(w)，与已审cosineResidual完全相同。定义F_n(z)=U_nφ(z)、G_n(z)=U_n1(z)。起点|z|≤h。

冻结结论：

1. 对所有n，0≤F_n(z)≤G_n(z)≤1。对所有k，精确缺陷恒等式
   F_(k+1)(z)−ρ F_k(z)=U_k r(z)。
   所用r及其绝对值为有界Borel，所有积分真实可积；不添加ν矩、中心或方差条件。
2. 给定m自然数、ε≥0，若对所有|w|≤h有U_m|r|(w)≤ε，则对所有k≥m，
   |F_(k+1)(z)−ρF_k(z)|≤ε G_(k−m)(z)。
   包含k=m和m=0；使用自然减法时必须显式利用m≤k。该条件是R3型输入，不由本模块证明。
3. 给定A,B≥0，若对所有|w|≤h有G_m(w)≤Aφ(w)+B，则对所有k≥0，
   G_(k+m)(z)≤A F_k(z)+B G_k(z)。
   该条件是R4型输入，不由本模块证明；不把φ在区间外的可能负值用于闭源域序比较。
4. 若另有ρ>0，定义Fhat_n=(ρ^n)⁻¹F_n(z)、Ghat_n=(ρ^n)⁻¹G_n(z)。从2、3精确推出
   |Fhat_(k+1)−Fhat_k|≤[ε(ρ^(m+1))⁻¹]Ghat_(k−m) (k≥m)，
   Ghat_(k+m)≤[A(ρ^m)⁻¹]Fhat_k+[B(ρ^m)⁻¹]Ghat_k。
   不偷偷把归一化因子说成统一有界，不假设ρ为实际特征值。
5. 若0<ρ≤1，则所有n有Ghat_n≥0，且n≤2m时Ghat_n≤(ρ^(2m))⁻¹；同样Fhat_n≥0。该D4精确有限界不供应B1初值或随h统一常数。
