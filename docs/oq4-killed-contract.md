# R1–R2 单步被杀余弦残差冻结 v1

源 current/oq4/b01/proof01.md §6 R1–R2。只关闭普通一步期望与闭边界几何；不假设实际长时间主特征值或R3。

令ν为ℝ上Borel概率测度。对实a,h,z，定义

Kcos(ν,a,h,z)=∫ [若 |z+y|≤h 则 cos(a(z+y))，否则0] dν(y)，
ρ(ν,a)=∫cos(ay)dν，η(ν,a)=∫sin(ay)dν。

F-K1 精确恒等式（任意实a,h,z）：

Kcos−ρ cos(az)=−η sin(az)−∫_{|z+y|>h}cos(a(z+y))dν(y)。

F-K2 几何界：对h>0、|z|≤h、a=π/(2h)、每个实y，

|若 |z+y|≤h 则0，否则cos(a(z+y))|
≤a max(|y|−(h−|z|),0)。

含离开闭区间的严格killing、两端点cos(±π/2)=0、任意大跳跃及格点/原子。严禁把逐点残差除以边界为0的cos(az)。

F-K3 期望残差：除上述h,z外，假设id、y²、|y|³对ν可积，∫y=0、∫y²=1，β=∫|y|³。则 overshoot 函数 max(|y|−(h−|z|),0) 可积，且

|Kcos(ν,π/(2h),h,z)−ρ(ν,π/(2h))cos(πz/(2h))|
≤π³β/(48h³)+(π/(2h))∫max(|y|−(h−|z|),0)dν(y)。
