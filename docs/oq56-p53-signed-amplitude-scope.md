# Scope of SparseSignedAmplitude

The function is the fixed level amplitude with a fair sign on the existing Nat×Bool law. It is measurable and symmetric as a full Real pushforward measure, even when different tags have equal or zero amplitudes. It has genuine L1, mean zero, every positive real absolute moment, square integrability and exact unsigned-moment identities. Strict square positivity uses the inheritedCore. The exponential observable is integrable for every 0 < τ ≤ 1, including τ = 1, with actual integral at most 5/4.

All integral identities are obtained after honest signed and unsigned integrability. Category0 retains its actual residual mass; a nonintegrable Bochner default or Real singleton injectivity argument is not used.

The only project imports are the accepted coefficient moments and tagged-law integration modules. This realizes the one signed feature, before constructing the independent G/Z/A population. It does not prove iid sampling, a Real encoding, kernel/projection/operator properties, true denominator positivity, conditional event probabilities or final tails. In particular the feature-exponential claim is not a stretched-exponential claim about the complete kernel. P53/OQ6/RS2 remain OPEN.
