## Selected source-bound unit and its contribution

The candidate is the genuine **history-localized signed block** lemma
`h:lem:reflection`, rather than the full Fourier comparison. For
`F_i=f_(n-i)^ψ(W_i,Q_i)`, the source asserts, for every `0≤k≤n` and every
event `E∈σ(A_1,...,A_k)`,

```text
E[1_E sum_(i=k+1)^n Delta_i(ψ)] = E[1_E (F_n-F_k)],
abs(E[1_E sum_(i=k+1)^n Delta_i(ψ)]) <= P(E).
```

This pays an entire signed late block by the probability of a bad clock
event, with the actual constant one. Summing individual absolute bounds
would only give `(n-k)P(E)` and would lose this source argument. The
localized equality is not a consequence of merely multiplying the
already-proved unweighted expectation equality by `1_E`: a genuine
history-weighted one-step proof is needed.

### Actual finite history, including time zero

```lean
def lindleyHistory {n : ℕ} {Ω : Type*}
    (X : Fin n → Ω → ℝ) (k : ℕ) (hk : k ≤ n) : MeasurableSpace Ω :=
  MeasurableSpace.comap
    (fun ω => Shao.prefixPath (fun i => X i ω) k hk)
    (inferInstance : MeasurableSpace (Shao.Path k))

theorem lindleyHistory_eq_iSup {n : ℕ} {Ω : Type*}
    (X : Fin n → Ω → ℝ) (k : ℕ) (hk : k ≤ n) :
    lindleyHistory X k hk =
      ⨆ j : Fin k,
        MeasurableSpace.comap
          (X ⟨j.val, lt_of_lt_of_le j.is_lt hk⟩)
          (inferInstance : MeasurableSpace ℝ)
```

This is precisely the sigma algebra generated by the first `k` original
increments; it is not a new independence assumption or an arbitrary
filtration. The equality is part of the candidate, so the source's
quantifier over **all** history events is not silently narrowed to one
chosen class of cylinders. In particular history at `k=0` is the trivial
sigma algebra, and history at `k=n` includes the entire finite sample.
No completion of the sigma algebra is asserted or needed by the source.

### Actual history-weighted one-step identity

```lean
theorem iid_lindley_future_step_on_history
    (hX : ∀ i, Measurable (X i)) (hIndep : iIndepFun X μ)
    (hLaw : ∀ i, IdentDistrib (X i) (id : ℝ → ℝ) μ ν)
    (k : ℕ) (hk : k ≤ n) (E : Set Ω)
    (hE : MeasurableSet[lindleyHistory X k hk] E)
    (ψ : ℝ × ℝ → ℝ) (hψ : Measurable ψ)
    (hψ01 : ∀ s, 0 ≤ ψ s ∧ ψ s ≤ 1)
    (i : Fin n) (hi : k ≤ i.val) :
    (∫ ω in E, lindleyFutureKernel ν (n - (i.val + 1)) ψ
        (Shao.lindleyState (samplePath X ω) i.val
            (Nat.le_of_lt i.is_lt) + X i ω,
          Shao.prefixSquares (samplePath X ω) (i.val + 1)) ∂μ) =
      ∫ ω in E, lindleyFutureKernel ν (n - i.val) ψ
        (Shao.lindleyState (samplePath X ω) i.val
            (Nat.le_of_lt i.is_lt),
          Shao.prefixSquares (samplePath X ω) i.val) ∂μ
```

The zero-based `i` is source step `i.val+1`; `k≤i.val` is exactly the
source requirement that `E` is measurable before this increment. Ordinary
measurability of `E` under the ambient sigma algebra is derived from `hX`
and `hE`, not inserted as a separate input. The future still uses the
unchanged iid probability law `ν`.

## Proof obligations that must actually close

1. Expand the finite product measurable structure and prove
   `lindleyHistory_eq_iSup` using `comap_iSup` and `comap_comp`. For an
   arbitrary `hE`, `MeasurableSpace.measurableSet_comap` supplies a Borel
   prefix event whose exact inverse image is `E`.
2. Transfer the ambient iid path law to its actual canonical product law.
   Split the current coordinate with `measurePreserving_piFinSuccAbove`.
   Since `k≤i.val`, both the prefix event indicator and the true previous
   state/square sum are constant as that coordinate varies. Prove those
   prefix-dependence facts from the actual recursion/prefix definitions.
3. Prove measurability and genuine integrability of all weighted terms
   under the ambient finite measures before Fubini, subtraction or finite
   integral/sum interchange. Existing test/kernel unit bounds suffice;
   neither the increments nor their squares need be integrable here.
4. Use the already proved actual finite-product semigroup to establish the
   weighted one-step equality. Then the scalar reflection defect and
   finite cancellation give the block identity. No weighted-step,
   conditional-expectation, semigroup or block identity may be taken as an
   input hypothesis.
5. Both endpoint values lie in `[0,1]`; their difference has norm at most
   one. The set-integral norm inequality gives `(μ E).toReal`, with no
   sample-length loss.

The existing `iid_lindley_future_step` is unweighted. Applying it to
`μ.restrict E` is not justified: the original iid laws are generally not
preserved under history conditioning, and the restricted measure is
usually not a probability. The new proof must retain the original product
law and its genuine past-event indicator.

No frozen private helper is promoted or modified. Some prefix congruence,
measurability and coordinate-integral helpers in `LindleyTelescoping` are
private; a new file must prove the needed local helper facts or use public
finite-path/product APIs. It cannot rely on unstable `_private` names.

## Independent boundary and counterexample ledger

These are exact hand calculations, not Lean-checked candidate proofs.
They test nearby altered statements and explain why the proposed inputs
and absolute-value placement must remain fixed.

**B1 — history cannot be removed.** Let `n=3`, `k=0`, iid increments be
uniform on `{-1,1}`, and `ψ(w,q)=1_{w≥0}`. Choose the anticipative event
`E={A_1=A_2=A_3=-1}`, which has probability `1/8` and is not measurable in
the time-zero history. On that event the true reflected states are zero,
all regulators are one, and the future lengths are `2,1,0`. The actual
defects are respectively `1/2,0,1`, by direct averaging of the remaining
fair signs. Therefore

```text
abs(E[1_E sum Delta]) = (1/8)(3/2) = 3/16 > 1/8 = P(E).
```

Thus the mass-payment assertion with arbitrary measurable `E` would be
false. The actual block identity is also only an expectation identity,
not a pointwise equality of the signed defects and endpoint difference.

**B2 — taking absolute values term by term would change the theorem.**
Let `n=4`, `k=0`, `E=Ω`, use the same iid fair signs, and set the continuous
unit-bounded test `ψ(w,q)=(1+cos(πw))/2`. Every reflected state is an integer
and each regulator is zero or one. Averaging a future sum of `l` fair signs
multiplies `cos(πw)` by `(-1)^l`. Consequently `|Delta_i|=1` exactly when
`W_(i-1)=0` and `A_i=-1`. Those four event probabilities are
`1/2,1/4,1/4,3/16`, so

```text
E sum |Delta_i| = 19/16 > 1 = P(Ω).
```

The source's signed block and its outside absolute value are essential.

**B3 — empty/full blocks and zero energy.** At `k=n`, the selected sum is
empty and `f_0=ψ`, `Q_n=energy`, so the right-hand block difference is
identically zero. At `n=k=0` the same conclusion holds. At `k=0`, only a
trivial-history event is permitted, reducing to the existing global
identity or zero. Deterministic zero increments and noncentered laws are
allowed; there is no square-root denominator or positive-energy premise in
this finite unit.

**B4 — the unit payment constant is sharp.** A further independent check
after drafting the candidate takes `n=1`, `k=0`, `E=Ω`, the deterministic
increment law `ν=δ_(-1)`, and `ψ(w,q)=1_{w≥0}`. Then `W_1=0`, `U_1=1`,
`Q_1=1`, and the actual defect is `ψ(0,1)-ψ(-1,1)=1`. Both the signed
block bound and its endpoint form attain equality with `P(E)=1`.
Consequently no constant less than one works under the proposed inputs.
This also confirms that positive increment variance would be an
unnecessary and source-unfaithful extra premise for this finite payment.

unit must construct that genuine law and prove measurability/unit bounds
for that actual test. A generic theorem for an arbitrary `[0,1]` test does
not prove smoothness, a derivative estimate, a strict-CDF smoothing error,
or anti-concentration.

The required quantitative estimate for that probability is still open:

of the finite candidate and is not claimed to follow from it.
