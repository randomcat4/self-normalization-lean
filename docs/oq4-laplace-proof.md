# 正部 Laplace 支付的匿名推导

设 μ 是实直线上的任意 Borel 概率测度，L>0。记
f_L(x)=1-exp(-max(x,0)/L)，w_L(u)=L⁻¹exp(-u/L)，A_L=∫f_L dμ。

1. 由于 max(x,0)≥0，0≤f_L(x)≤1。函数连续，故对任意概率 μ 可积；积分也在 [0,1]。w_L 连续、处处正，且 ∫₀∞w_L=1、∫₀∞u w_L=L。这两式可用指数积分及分部积分直接得到，均为真正的有限积分。

2. 对每个 x，微积分基本定理给 ∫₀^{max(x,0)}w_L(u)du=f_L(x)。将非负被积函数作 Tonelli（加权层蛋糕公式），得到
A_L=∫₀∞w_L(u) μ{x>u}du。
这里 u>0 时 max(x,0)>u 当且仅当 x>u，所以尾事件严格不等号没有丢弃原子。尾质量函数是反单调的 Borel 函数，取值 [0,1]；因而右侧被积函数可测且由可积的 w_L 支配，真实可积。此步骤不需要 μ 的任何矩。

3. 对实际标准正态 γ=gaussianReal 0 1，负号推送保持 γ，且 γ 没有原子。于是 γ(Iio 0)=γ(Ioi 0)，而 γ({0})=0，总质量为1，故两者都等于1/2，Φ(0)=γ(Iic0)=1/2。已核验实际 Φ 全局1-Lipschitz，故对 u≥0、s=√q>0，Φ(u/s)≤1/2+u/s。

4. 保留冻结的 CDF 误差输入 |μ{y/s≤x}-Φ(x)|≤ε，ε=C_BE β/s。取 x=u/s；正分母保证 {y/s≤u/s}={y≤u}。补集关系对任意原子均精确给
μ(Ioi u)=1-μ(Iic u)≥1/2-u/s-ε。
乘非负 w_L 并积分，左侧是 A_L，右侧为1/2-L/s-ε。由 C_BE≥0、β≤L，得到
A_L≥1/2-(1+C_BE)L/s。
A_L≥0 仍单独成立；不要求显示下界为正。q≥1 仅保证 s>0，1≤β≤L 保留原量词。

5. 对任意 Borel 概率 ν，Π_q=Measure.pi(fun _ : Fin q => ν) 是实际概率测度，X(a)=prefixSum a q 是可测函数；其推送 μ=X_*Π_q 仍是概率。对该 μ 应用前述结果。可测推送积分公式把 A_L 精确改写为 Π_q 下的 ∫[1-exp(-max(prefixSum a q,0)/L)]，并由有界性直接给实际产品被积函数可积及 [0,1] 界。产品 CDF 输入经推送的可测半直线原像精确转成第4步输入。未作任何生存条件化，未加入矩、中心、密度或格点条件。
