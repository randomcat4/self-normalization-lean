# OQ4 被杀核有限迭代接口冻结 v1

源 current/oq4/b01/proof01.md §1 的 K_h^n、§8 D0/D1 和 §9 P1 所用的正性与半群代数。只把已冻结的真正单步 killedKernel 迭代起来；不把 iid 路径表示、O0、R3/R4 或长时间 K 当前提/结论。

ν为ℝ上的任意 Borel 概率测度，h为任意实数，P=killedKernel ν h。定义实际 Mathlib 核幂 P^n（n自然数，P^0=id核）及实测试作用

U_n f(z)=∫ f(w) d(P^n(z))(w)，G_n(z)=U_n 1(z)。

冻结目标：

1. 每个核幂为统一有限核；每行总质量≤1，并有实数版本。P^0(z)=δ_z。n≥1时每行P^n(z)-几乎处处|w|≤h；若起点|z|≤h，则所有n（包括0）均有该行AE支持。
2. 对任意有界Borel实函数f（Measurable f，存在实M使所有w满足|f(w)|≤M），每个n,z的积分真实可积；U_n f作为z的函数可测且有界。精确界为|U_n f(z)|≤M G_n(z)，同时0≤G_n(z)≤1。不得用不可积积分默认0。
3. U_0 f(z)=f(z)，U_1 f(z)与已审单步杀死测试积分接口完全相同；对所有自然数m,n有真实半群恒等式U_(m+n) f(z)=U_m(U_n f)(z)。内层作用的可测、有界及外层真实可积性必须已证明。
4. 对有界Borel测试证明实线性（加法、实数倍）及绝对值支配|U_n f(z)|≤U_n |f|(z)。对起点|z|≤h及任意n，只要f(w)≤g(w)在闭区间|w|≤h上成立，便有U_n f(z)≤U_n g(z)。对任意z若f≤g全实轴亦有同样序关系。每次积分线性/比较使用实际可积性。

ν无需矩、中心、密度、非格点或有界增量假设。允许h=0原子，h<0时源域为空但核幂接口仍按上述全实轴延拓有效。n=0不能错误宣称任意区间外起点的δ_z受闭区间支持；不得偷偷在时0也杀死任意z。

这是§1/8/9使用的核代数基础；不认证P^n与有限iid增量路径事件的等价，不推出随机游走生存概率，不证明R3/R4/O0、D0/D1的概率输入、Brownian近似、K/Kv或OQ4。拟文件Shao/OQ4/KilledIteration.lean，证明仅使用已审单步核和Mathlib标准核组合，不改公共定义/根导入/manifest/cache。
