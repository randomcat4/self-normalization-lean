## 独立数学与边界核查

### 旧点整数与 J=0

已独立审查 U1 给四旧法向值依序为 `n_i=(-9,7,6,12)`。对任意 J，取真实整数证人

```text
m=n_i·(2:ℤ)^J.
```

整数幂嵌入实数后恰为 `(2:ℝ)^J`，故第一目标在旧点侧成立，包含负旧法向值和 J=0。J=0 时 `Fin 0` 为空，没有新增分母需要消去；无需额外假设 J>0。

### Fin J 的精确分母消去

若 k:Fin J，则 k.val<J，从而 `k.val+1≤J`。新增法向值与共同缩放给

```text
2^J Y(addedAtom k.val)
  = 6·2^J + 2^J·(2^(k.val+1))⁻¹
  = 6·2^J + 2^(J−(k.val+1)).
```

底数 2 非零，且自然数指数差的使用点满足 `k.val+1≤J`，所以没有在实数除法或自然数截断减法上丢失条件。精确整数证人可取

```text
m = 6·(2:ℤ)^J + (2:ℤ)^(J−(k.val+1)).
```

右端确为 ℤ 嵌入，不是“接近整数”的实证人。边界 k.val=J−1 时剩余幂为 2^0=1，仍精确整数；J=1 首新增点法向值 13/2，缩放后为 13，指标无误。

### 全索引最终性与频率恒等

对固定旧索引，全部 J 都整格。对固定新增自然数 k，只需最终 J≥k+1。故每个固定 i 有其自己的最终阈值，正是第二/第五目标的量词次序。不能交换为某个有限 J 同时覆盖全部无限原子：例如在任意给定 J 取新增指标 k=J，缩放值为 `6·2^J+1/2`，并非整数；当前接口未作此错误承诺。
