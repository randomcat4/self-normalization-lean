# 原文好事件的补集概率

本模块定义字面的归一化好事件，并证明：固定概率模型与可测、二阶可积、均值零且二阶矩为一的 g 后，存在一个 c>0，使每个 n>0、y≥1 都满足好事件补集概率不超过 exp(-c*n)+4*exp(-(y*sqrt(n))/2)。c 的选择先于 n、y。定义本身保留所有 n 与实数 y；概率定理保持 n>0。

好事件补集仍是严格低能量事件或严格上尾事件，包含原阈值边界／原子处理。证明没有除以随机能量、概率或样本和。唯一源码修复是在旧84行文件前言插入实际 autoImplicit=false 设置及分隔空行；全部数学声明与证明字节保持，并由同一独立审查者组合复核。
