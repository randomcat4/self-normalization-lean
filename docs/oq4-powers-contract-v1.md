# OQ4 自由余弦系数正性、幂及对数误差冻结 v1

源 current/oq4/b01/proof01.md §6 R0、§8 ρ^(-m-1)及D4统一界、§9末尾N logρ误差。使用已证CosineCoefficients的实际自由一步系数，不称其为杀死核特征值。

ν是ℝ Borel概率测度；id、y²、|y|³真实可积，均值0、二阶矩1。β=∫|y|³dν，M≥0且β≤M。h≥1，π(1+M)≤h；这是源“充分大h”的一个明确充分阈值。设ρ=cosineCoefficient ν (π/(2h))，λ=π²/8。

冻结目标：

1. 对实际ρ，
   1−π²/(4h²)≤ρ≤1−π²/(16h²)，且3/4≤ρ<1（从而ρ>0）。
2. 对每个自然数n，
   (ρ^n)⁻¹≤exp(π² n/(2h²))。
   进一步若(n:ℝ)≤2h²，则(ρ^n)⁻¹≤exp(π²)。取m=⌊h²⌋₊，证明源所需两个明确统一界
   (ρ^(m+1))⁻¹≤exp(π²)，(ρ^(2m))⁻¹≤exp(π²)。
3. 实际对数误差有安全显式常数
   |logρ+π²/(8h²)|≤[π³M/48+π⁴/8]/h³。
   对每个自然数N，精确推出
   |N logρ+π²N/(8h²)|≤[π³M/48+π⁴/8]N/h³。

允许原子、不对称分布和任意大跳；无密度、第四矩、有界增量或格点条件。n/N=0覆盖；h阈值和矩前提不能省略。参数M共同固定时，显示常数只依赖M；不使用未证O0/R3/R4或Brownian结果。

该单元关闭源R0之后的系数正性与有限归一化控制，以及最后指数替换所需的定量对数误差。它不证明ρ为真正谱特征值、不证明B1初值、任何长时间核极限或4/π，也不证明实际K/Kv/OQ4。拟Shao/OQ4/CosinePowers.lean。
