# R3 的解析平均支付接口冻结 v2

源 current/oq4/b01/proof01.md §6 R2/R3/R5/R6。关闭从明确有限时层质量输入到平均残差的解析步骤；不供应O0概率估计、不把完整R3或K当输入。

ν为ℝ上的概率测度，id、y²、|y|³可积，∫y=0、∫y²=1，β=∫|y|³。κ为ℝ上有限测度，κ.real(univ)≤1，κ-几乎处处|w|≤h，h>0。C≥0。令d(w)=h−|w|、L=floor(h)+1、E_j={w | j≤d(w)<j+1}。假设每个自然数j<L满足

κ.real(E_j)≤(C/h²)(j+1)。

用已正式冻结的一步定义Kcos及自由系数ρ，a=π/(2h)，r(w)=Kcos(ν,a,h,w)−ρ(ν,a)cos(aw)。结论：r的绝对值对κ可积，且

∫|r(w)|dκ(w) ≤ [π³β/48 + 2π C(∫|y|dν(y)+β)]/h³。

可再以概率空间逐点|y|≤1+|y|³导出无额外前提的安全上界

∫|r|dκ ≤ [π³β/48 + 2π C(1+2β)]/h³。

该式在β≤M且固定层质量参数C的共同类上给出显式C_{M,C}/h³。只有另由O0证明C=C(M)后，才可把源应用中的常数记为只依赖M的C_M。若κ确为m步被杀终点子概率law，层质量假设必须另由O0正式实例化，才可称源R3概率结论闭合。本模块只证明解析约化；不引入未证长时间核假设。

任意大跳、ν/κ的原子、w=±h、整数h顶层、κ=0均保留。深度范围来自κ-a.e.支持；不得加强为κ在整个ℝ上的逐点支持，不假定密度、第四矩或有界增量。必须实际证明所需被积函数的可测性/可积性，不把默认的不可积积分0当界。
