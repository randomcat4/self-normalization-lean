同样适用于任意实 Borel 目标集合，故对固定 z 的两个原律分布，其 CDF 的绝对距离也至多 B；不需先证明 P(T=τ)=0。这是物理/截断间的比较，未声称任一方已经接近 Gaussian。当前层 z 和新的 τ 必须区分：改变 τ 不改变这里已固定的 clip_z。

与 v151 的编码五关系相接时，其有限 ε 的精确未除法事件运输仍可能带原 p0=P(V=0)。258 现在明确给 p0≤B，也把它和其他原坏事件作为同 H_z 补集的一部分付款，因而不再只是一个无数值控制的符号项。但若只把两个各≤B 的比较误差作三角相加，所得可用界是 2B；不能未经共同事件包含就保留 B。闭尾与严格尾不能互换，真实原子的质量也没有被证明为0。

此外，v151 的 Tη(τ) 随 τ 改变；“对每个 τ 的五关系运输”仍不构成一个与 τ 无关的编码变量的 CDF。当前 Q 的 M_{ε,z} 包络适用 τ=z 或 |τ|≤z，不能由 (10) 推出同一扰动包络支配全部实 τ。Gaussian CDF、Gaussian-relative 闭尾以及外部 Scalar Shao–Zhou tail/CDF 输入，仍须分别消费各自已接受接口；258 只有原事件付款和物理一致性，不提供外部引擎存在性或其全部应用。
