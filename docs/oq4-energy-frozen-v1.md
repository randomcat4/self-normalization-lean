## 对象与前提

ν 是 ℝ 上 Borel 概率测度，x↦x² 与 x↦|x|³ 真正 ν 可积，且 ∫x² dν=1。令 β=∫|x|³ dν。这里只选 E1 中偶权重的有限归一化子问题：不需要中心或 id 可积前提，因此主实例在冻结时明确省略二者，使局部结论更强；完整 E1 的均值结论仍须原中心条件。不得把 β 改为随意上界参数或把 β≥1 作为额外分布条件。

实参数 T≥0，h≥1，s∈ℝ，|s|≤T。量词对全部上述 ν,T,h,s；常数只依赖 T。定义

B_h={x:|x|≤2h}，w_{h,s}(x)=if |x|≤2h then exp(s*x²/h²) else 0，
Z_{h,s}=∫w_{h,s} dν，C_Z(T)=1/8+T/2+exp(4T)*T²。

建议 Lean 名 energyWeight、energyNormalizer、energyNormalizerErrorConstant；定义必须是真实权重/实积分，不得用抽象参数代替。闭截断包含端点原子；补集为严格 |x|>2h。零点权重为一，s=0 时 Z=ν.real B_h，不假定其等于一。

## 冻结结论

1. 对任意实 h,s，w_{h,s} 为 Borel 可测且逐点非负。对上述 T,h,s，逐点 w_{h,s}(x)≤exp(4T)，并由此证明真正 ν 可积，不得使用不可积实积分的默认零。
2. 给出源式(4)的真实有限支付。尾质量及三项截断积分分别满足
   ν.real{x:2h<|x|}≤β/(8h³)，
   ∫(if 2h<|x| then |x| else 0)dν≤β/(4h²)，
   ∫(if 2h<|x| then x² else 0)dν≤β/(2h)，
   ∫(if |x|≤2h then x⁴ else 0)dν≤2hβ。
   三个积分中的函数真正可积必须为结论或已证明的可追溯引理。允许这些辅助界对更一般的 h>0 成立，最终 N0 仍包含全部 h≥1。
3. 真实归一化因子有限正下界及上界：
   (3/4)*exp(-4T)≤Z_{h,s}≤exp(4T)。
   下界是源 E1 的有限加强：由单位二阶矩、h≥1 得截断质量≥3/4，再用截断内权重≥exp(-4T)。不增加 Z>0、支撑有界或矩小性假设。
4. 一阶展开与显式误差：
   |Z_{h,s}-1-s/h²|≤C_Z(T)*β/h³。
   常数的三项分别对应尾质量、截去的二阶项和指数二阶余项。不得把常数改为依赖 ν、β 或 h，也不得增加全局第四矩或正二次指数矩。
