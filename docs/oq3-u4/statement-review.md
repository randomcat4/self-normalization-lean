## 独立原始库定义与数学边界核查

本轮仅只读指定服务器固定 Mathlib 原始源 `Mathlib/MeasureTheory/Measure/Tilted.lean`，未读作者 API planning/log。原始 42–43 行是

```text
μ.tilted f = μ.withDensity (x ↦ ofReal(exp(f(x)) / ∫exp(f)dμ)).
```

所以 `.tilted` 的参数确实是指数中的对数权重，而非直接密度。原始 46–48 行在指数不可积时将倾斜测度总化为零；原始 280–281 行无条件给 `μ.tilted f ≪ μ`；276–278 行的精确互逆倾斜明确要求原 μ 是概率测度且指数真实可积。当前接口的门足以满足这些条件。

### 紧支撑连续可积桥与严格正 Z

`|x|≤β` 几乎处处将 μ 集中在紧区间 `[-β,β]`。连续 f 在此紧集上范数有有限共同界，其全局连续性又给所需可测性；概率测度总量有限，因此 f 可积。该桥不宣称无界支撑下的连续函数可积，也不把 U3a 只对 ell≥0 的统一新增特征界延伸到负 ell。

对任意固定实 ell，`exp(−ell Y(x))` 连续，故上述桥给 π_w 下真实可积。hw 与 HasSum w 1 经 U3b 给 π_w 是非零概率测度。指数处处严格正，故实际积分 Z 严格正；在紧集上的正最小值也可独立给出严格正下界。没有利用不可积积分的零值或仅非负性来证明正 Z。

### 原律、单点与无条件支撑

在概率门下，Z 为有限严格正实数，P 的密度是真实非负函数 `exp(−ellY)/Z`，积分为 1。于是 P 是概率测度，连续函数桥再次给 x 以及 `exp(ellY)` 对 P 可积。

对实轴 `{a_i}` 使用 U3b 的精确单点质量 w_i，再乘同点的密度，得到 `w_i exp(−ellY(a_i))/Z`。这比值非负，故扩展非负/转实数版本相符；若 w_i>0，则指数和 Z 均严格正，得到严格正单点质量。w_i=0 时质量正确为零，没有不当地承诺所有一般 w 的原子都正。

对于任意有符号或不可求和的一般 w，原始库无条件绝对连续性保证 P 的 AE 性质由 π_w 继承。即使倾斜落在总化零测度分支，AE 支撑界仍真；当前无条件目标只输出该界，完全没有宣称概率、Z>0 或单点比值公式。

### 中心化、再倾斜及正向归一化

centered 的 hm 第 0 坐标给真实质量 HasSum 1，故其未单独写 hs 不是漏前提。第 2 坐标经 U3b 给 `x exp(−ellY)` 对 π 可积且积分 0。P 的真实 x 可积性由支撑桥保证，实际积分变换给

```text
∫x dP = (∫ x exp(−ellY(x)) dπ)/Z = 0.
```

对前向指数，积分变换中指数逐点相消：

```text
∫exp(ellY)dP = (∫1 dπ)/Z = 1/Z.
```

可积性已独立由 P 的概率性和固定支撑给出，Z>0 也已要求证明。再倾斜时新密度为 `exp(ellY)/(1/Z)`，与旧密度相乘为 1，因此完整测度精确返回 π；库的互逆倾斜定理亦有相同结论。这里不能把非概率一般 μ 的两次倾斜等同 μ，当前签名的概率门正确避免此问题。

ell=0 时 Z=1、P=π、正向归一化为 1，所有一般倾斜目标相容。任意负 ell 仍由同一紧支撑桥处理，不需额外指数矩假设。source family 一次使用前序 U3a/U3b 的 p/q/eps，之后对每条合格 r 使用同一 w 的质量、四矩和支撑；Z 可随该固定 r 改变，但所有定义中的 Z 始终与同一 w 绑定，没有随 n/J 重新选择原律。
