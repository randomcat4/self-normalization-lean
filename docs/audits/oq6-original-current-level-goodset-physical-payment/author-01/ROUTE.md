# 冻结命题到证明的来源路线

1. 一次固定原 g 的 P54 frontier 选择 cg；所有包络参数、样本长度、核、rho 和 z 留在其后的量词内。P54 的 n≥4 原样交给目标，不增加 eventual 限制。
2. 对相同原 r、w 和所有冻结前提，以 C0=512、当前 rho、当前 z 实例化 P54。q、K、G、C2、Hsource 与付款的定义逐项相同；P 只是原 `sampleLaw n μ` 的名称。
3. Hsource 成员给原始偏差的当前 z² 界。当前 z 的 generic 裁剪收缩给当前 D2z 的 1/32 界，进而给 Ssafe 的 1/8 界。
4. rawdelta>−1/8 提供 literal 比较所需 −1/2 下界。显式 hGeometry 只在当前 z 的 literal 比较中使用；它没有被假装成包络窗口或倾斜窗口的自动后果。
5. 同一个 literal 比较给当前 D2z=rawdelta、真实分母正和当前 clipped=physical。原 P54 真实分母因式分解不改变任何统计量。
6. generic 可测性合同在原 mΩ 的样本乘积空间下给 physical、clipped、Eclip 可测；Hsource 可测直接来自相同 P54 合同。没有任何关于未来 mN0 的结论。
7. 四种坏事件整体被 Hsource 补覆盖。每一付款结论都是测度单调性加同一原付款界，保留精确 3exp(−q)+exp(−cg n)+4exp(−z√n/2)。

承重来源、完整合同、完整实参/返回类型见 `INPUT-BINDINGS.json`、`PRODUCER-CONTRACTS.json`、`PRODUCER-CALLS.json`。`SOURCE-SLICES.json` 可无损重建冻结前缀、声明头、新证明体和结束段。
