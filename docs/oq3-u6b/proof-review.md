令 μ 为实数上的测度。定义

- `jointPhase ξ η x = exp(i(ξx + ηx²))`，值域为复数；
- `jointCharacteristic μ ξ η = ∫ jointPhase ξ η x dμ(x)`，为 Bochner 积分。

六个公开目标的独立数学翻译如下。

1. 任意实数 ξ、η、x，上述复相位的范数等于 1。
2. 任意实数上的概率测度 μ 和任意 ξ、η，相位函数关于 μ 可积。
3. 同样条件下，联合特征函数的范数不超过 1。
4. 若该联合特征函数的范数等于 1，则任意两个满足 `0 < μ.real {x}`、`0 < μ.real {y}` 的实数原子，其相位相等。只断言正质量点，不断言所有支撑点逐点相等。
5. 两点 x、y 的相位相等，当且仅当存在整数 m，使 `ξ(x−y)+η(x²−y²)=2πm`。
6. 若 μ 是概率测度，且每个预先定义的 `fixedAtom i` 都有严格正的实数质量，则对任意 `ξ ≠ 0 ∨ η ≠ 0`，联合特征函数的范数严格小于 1。该签名对参数使用析取，排除且仅排除向量 (0,0)。
