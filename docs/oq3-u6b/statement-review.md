## 独立数学与边界可行性检查

### 单位范数、可积性与实际积分界

对任意实多项式值 t，`exp((t:ℂ)i)` 的实指数部分为零，故复范数为 1。jointPhase 关于 x 连续可测，且范数恒 1；任意概率测度有限，因此相位真实可积。积分三角不等式给 `‖∫jointPhase dμ‖≤∫1dμ=1`。这一论证对无界支撑、非原子 μ 和任意实系数均成立，不借不可积积分默认为零来放行。

### 模一等号到 AE 常相位，再到两个正原子

令 `u(x)=jointPhase xi eta x`、`z=∫u dμ`，假定 `‖z‖=1`。定义实缺陷函数

```text
g(x)=1−Re(conj(z)u(x))≥0.
```

因为 u 与 z 都为单位模，g 连续可测且在 [0,2] 中，真实可积。复积分及实部的有限线性运算给

```text
∫g dμ = 1−Re(conj(z)·z) = 1−‖z‖² = 0.
```

故 g=0 几乎处处；等价距离恒等式 `‖u(x)−z‖²=2g(x)` 给 u=z 几乎处处。这为声明所需的三角等号桥提供独立完整数学理由，不需要假定 μ 是原子测度。

概率性确保每个 singleton 有限。若 `mu.real {x}>0`，则真实 μ{x}>0；若 u(x)≠z，则 singleton {x} 包含于 AE 等式的零测异常集，迫使 μ{x}=0，矛盾。因此两个有严格正单点质量的 x,y 都精确满足 u(x)=z=u(y)。没有从 AE 直接推广到所有实点，也没有假定所有拓扑支撑点都自动有正质量。

### 2πℤ 等价的两个方向与符号

令 `A=xi x+eta x²`、`B=xi y+eta y²`。两个复指数相等，当且仅当 `exp(i(A−B))=1`；对实 t，`exp(it)=1` 当且仅当 `t=2πm`、m∈ℤ。因此精确差分是

```text
A−B = xi(x−y)+eta(x²−y²) = (2π)m.
```

这证明“相等⇒整数差”，而“整数差⇒相等”由 exp 的 2πi 周期性得到。不是 π 整数、遗漏 i 的实指数周期，也不是仅单向蕴含。x=y 和 xi=eta=0 的退化情形均由 m=0 正确覆盖。

```text

```
