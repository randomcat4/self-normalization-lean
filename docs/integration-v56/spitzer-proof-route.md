## 2. 一般位置仅存在于有限证明内部

固定 `n` 与带标签向量 `a : Fin n → ℝ`。generic 条件是任意两个非空、不交的标签子集的坐标平均不同，即候选的 `DistinctDisjointMeans a`。它比“所有不同非空子集平均不同”的常见写法更弱，已足够以下每一步。

**为什么足够。** 对一个无重复标签词，两个严格嵌套的非空前缀平均相同，会强迫较短前缀与新增非空段平均相同；两段不交，矛盾。对一个循环，两个不同的中心化前缀相同，会强迫两者间的非空段与其非空补段平均相同；同样矛盾。两个不同分块之间的斜率相同也直接违反条件。

**generic 向量存在。** 对长度归纳。已有长度 `n` 的 generic 向量时，新增坐标 `y`。每一对不交非空子集若都不含新标签，就由归纳假设处理；若包含新标签，它只出现在一侧，平均相等的方程中 `y` 的系数非零，故至多排除一个实数。标签子集对只有有限多个，从有限禁集外取 `y`。空长度条件真。

**稠密性。** 先取得一个 generic 方向 `v`。对于任意 `a`，每个不交非空子集对的平均差，在 `a + t • v` 上是 `A + t B`，且 `B ≠ 0`。所以所有约束总共只排除有限多个 `t`。在 `(0, ε/(‖v‖+1))` 内选不在此有限集中的 `t`，用 `‖t • v‖ = |t| ‖v‖ < ε` 保证任意精度；分母加1也覆盖空维情形。这证明 `Dense {a | DistinctDisjointMeans a}`，不需要实数超越性、随机扰动、Baire 理论、矩或无原子。

这两步是实际待证引理，不是“generic 由常识成立”的占位。它们在有限维确定性层发生，不改变被积分的真实概率律。

## 3. 唯一弦下旋转

设词 `w` 长度 `k > 0`，标签无重复，总和 `T`，斜率 `μ = T/k`。令

    c_j = sum(w.take j) - j μ,    0 ≤ j ≤ k.

有 `c_0 = c_k = 0`。在半开索引集 `0,…,k-1` 上，`c_j` 两两不同：若 `c_i = c_j` 且 `i < j < k`，则区段 `[i,j)` 的平均等于 `μ`，其非空补段平均也等于 `μ`，与 generic 条件矛盾。故有限最大值在唯一的 `r` 取得。

把 `w` 旋转为 `drop r ++ take r`。任意长度 `0 < j < k` 的中心化前缀是 `c_(r+j mod k) - c_r`，严格小于零，因此此旋转严格低于连接首尾的弦。反过来，若从 `r'` 开始的旋转所有内部中心化前缀严格为负，则 `c_r'` 大于其余每一个 `c_j`，所以 `r' = r`。

这是 `exists_unique_rotation_strictBelowChord` 的自包含证明。两个端点的零值只保留一次索引；不能在闭索引集 `0,…,k` 上错误地声称最大值唯一。`k = 1` 时唯一旋转的内部条件为空。

## 4. 唯一降斜率弦分块

对任意标签排列词 `w`，取非空前缀平均的唯一最大者，设长度为 `k`，斜率 `μ`。第2节已说明这些前缀平均互异。因此所有真前缀严格低于该弦，前 `k` 项组成第一个块。

对剩余词递归。若剩余词某个前缀的平均 `μ' ≥ μ`，将它拼到第一个块后，所得原词前缀的平均至少为 `μ`：严格大时与最大性冲突，相等时与唯一性冲突。故下一个块的斜率严格小于 `μ`。重复得到所有块严格降斜率、每块内部严格低于弦。

**唯一性反向证明。** 若已经有满足这两个条件的分块，那么第一个块末端的前缀平均正好为第一块斜率。更短前缀的平均更小；更长前缀是第一块及后续完整块/最后一个真前缀的加权平均，各后续项都严格小于第一块斜率。因此第一块末端必为全词前缀平均的唯一最大者。删除它后递归，全部块唯一。

这用词长度严格下降的良基递归实现，不必先建立几何凹包。`FaceDecomposition` 是完整有限列表不变量：拼接等于原标签排列、每块非空且弦下、斜率两两按出现顺序严格递减。空词的唯一分解为空列表。

## 5. 带标记双射与逆映射

以下使用1起始增量位置，最后转换成 `Fin n` 的0起始索引。

**正向。** 输入排列词 `w` 和标记 `q ∈ {1,…,n}`。在其唯一分块中，取包含第 `q` 个增量的块；令该块左右边界为 `g,d`，满足 `g < q ≤ d`。写成四段

    A = w[0:g], B = w[g:q], C = w[q:d], D = w[d:n].

令 `k = d-g`，输出长度标记 `k` 和排列词

    w' = C ++ B ++ A ++ D.

全部标签仍且仅出现一次，故 `w'` 给出一个真正的排列。`k ∈ {1,…,n}` 对应输出第一分量 `k-1 : Fin n`。`q=d` 时 `C=[]`，必须保留这个边界。

**逆向。** 任意给定输出 `(k,w')`：

1. 取首 `k` 项为 `Q`，余词为 `R`。`Q` 非空、标签无重复。
2. 按第3节，取得唯一的旋转索引 `r ∈ {0,…,k-1}`，使 `H = rotateWord Q r` 严格低于其弦。其斜率为 `μ`。
3. 对 `R` 取第4节唯一降斜率分块。各块标签与 `H` 不交，其斜率不等于 `μ`。故存在唯一插入位置，使较大斜率的块在 `H` 前，较小斜率的块在其后。写余词为 `A ++ D`，返回原词 `A ++ H ++ D`。
4. 设 `t = k-r`，则 `1 ≤ t ≤ k`，并且 `rotateWord H t = Q`。原标记恢复为 `q = length A + t`。若 `r=0`，则 `t=k`，标记是块末端而不是不存在的第0个增量。

**互逆必须真正证明。** 正向取出的块本来就是唯一弦下旋转；余下块已经严格降斜率，因此逆向取回同一块和同一位置。反向插入后得到一个合法 `FaceDecomposition`，由唯一性它正是正向算法读取的分块；第4步的旋转代数又恢复原 `Q`。这分别给出两条逆等式。`List.ofFn` 到排列的回转还需证明全标签性与无重复，不能只凭实数取值唯一性。

`n=0` 时标记积类型为空，取空类型上的恒等等价，最大值公式真值为空量化。

## 6. 最大值等式和真正有限恒等式

设一个合法降斜率分块的块总和为 `T_1,…,T_m`。块内曲线低于弦；若块斜率为正，弦从块左端升至右端，该块最大值不超过右端；若斜率为负则不超过左端；若斜率为零，两端相同且内部更低。严格降序的斜率意味着所有正块在所有负块前。因此整条路径含初始零的最大值正好是

    M(w) = Σ_i max(T_i,0).

删除第5节标记所在的块后，余词 `A ++ D` 的原分块继续合法，其最大值等于去掉对应正部后的和。输出首 `k` 项 `C ++ B` 的总和仍为 `T`。因此得到候选中的逐点等式

    M(w) = max(sum(w'.take k),0) + M(w'.drop k).

这不是原排列上任意切割的逐点等式；必须经带标记双射。

对该等式应用 `x ↦ exp(-x/L)`，用指数乘法把右边变成两变换的积。在标记和排列的有限积类型上按双射重索引：左边每个排列重复 `n` 次，右边每个正切割长度与每个排列恰好一次。因此得到 `finite_spitzer_cut_identity` 的 generic 版本。

两边都是 `a` 的有限连续函数：重排、头尾限制为坐标映射，前缀为有限和，最大值已经有 `Shao.continuous_maxWithZero`，`max`、除固定实数与 `Real.exp` 连续。generic 集稠密，所以两个连续函数在所有 `a : Path n` 上相等。**此处得到任意实增量、并列、重复值和零值均有效的真正有限生产者。** 不需要对概率律加无原子条件，也不需要控制有数据依赖的坏事件。

## 8. 真正收敛母函数的解析求解

令 `a_n`、`b_n` 满足候选解析引理的全部前提。定义实际实函数

    A(x) = Σ_{n≥0} a_n x^n,
    B(x) = Σ_{n≥0} b_(n+1) x^(n+1)/(n+1).

给定目标 `0<s<1`，取 `r=(s+1)/2`，在开连通区间 `(-r,r)` 上工作。由于 `|a_n|≤1`、`|b_(n+1)|≤1`，原级数均绝对收敛。不要将只针对正 `s` 的已有收敛引理无说明套给负 `x`；在这个对称区间直接用 `|x|^n` 支配。

为求导，将 `A` 写为 `a_0 + Σ_{n≥0} a_(n+1) x^(n+1)`。各导数分别受 `(n+1) r^n` 和 `r^n` 一致支配，二者可和。在0处两个去常数级数都为零。由已读的局部逐项求导接口得到

    A'(x) = Σ_{n≥0} (n+1) a_(n+1) x^n,
    B'(x) = Σ_{n≥0} b_(n+1) x^n.

绝对收敛 Cauchy 乘积给出 `A(x) B'(x)` 的第 `n` 个系数为 `Σ_{j=0}^n b_(j+1) a_(n-j)`，由**已证明的实际递推**恰等于 `(n+1) a_(n+1)`。因此 `A'=A B'`。

令 `F(x)=A(x) exp(-B(x))`，链式及乘积求导给 `F'=0`。在开连通区间上，已读均值定理接口给 `F(s)=F(0)=1`。因为 `exp(B(s))` 非零，得 `A(s)=exp(B(s))`。这两函数就是已存 `laplaceG a s` 与 `laplaceW b s`，不是形式幂级数的未经收敛求值。
