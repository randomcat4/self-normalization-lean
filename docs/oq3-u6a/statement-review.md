## 独立数学与边界可行性检查

### 两个极限

`dyadicMesh j=(1/2)^j`，其中实数 `|1/2|<1`，故趋于 0。指标平移 j+1 仍趋零，因而 `10−dyadicMesh(j+1)→10`。实平方根连续，平移加 4 给 `addedAtom j→4+√10`。所有新增根号参数也已由 U1 的 `dyadicMesh≤1` 保证非负；没有用某项已经等于其极限的错误推理。

### 固定格距的最终零性

给定固定 c>0，f→0 保证最终 `|f_j|<c`。若此时 `f_j=c m_j` 且整数 m_j≠0，则 `|m_j|≥1`，从而 `|f_j|=c|m_j|≥c`，矛盾。因此这些尾项的整数均为零，得到最终 f_j=0。

该结论不排除有限多个早期非零项，也不要求各项使用同一整数 m。c 必须在全序列之前固定；若允许 c_j→0，例如 f_j=c_j≠0，最终零结论就会失败。当前签名正确阻止这种量词偷换；阈值可依赖固定 c 与 f，不声称对全部 c 统一。

### 从全原子格点关系排除两个投影系数

由 hmem 限制到新增自然数侧，定义

```text
F_j = xi(z_j−β) + eta(z_j²−β²).
```

前述原子极限及有限实代数给 F_j→0；同一固定 c 的格点门给最终 F_j=0。对每个足够大 j，恒等式

```text
F_j = (z_j−β) · (xi+eta(z_j+β))
```

中 `z_j−β≠0`，因为 U1 已证明每个新增点严格小于 β。因此最终 `xi+eta(z_j+β)=0`。取阈值之后两个不同指标（例如 N 与 N+1），U1 的新增单射性保证两个原子不同。相减得到 `eta(z_N−z_(N+1))=0`，从而 eta=0，再代入得到 xi=0。

这里使用了两项不同原子，不是只凭一条线性关系推出两个系数都零；也没有从收敛本身误推出序列单射。虽算术证明只需新增侧，hmem 对完整索引 I 的强量词忠实对应源全支撑常相位，且保留同一实际旧中心点 β。

xi=eta=0 的退化投影当然满足 hmem，结论与之相容。c≤0 不在一般离散引理的声明域；c>0 是显式源格距条件。全族条件不能被任意有限阶段条件替换，当前未作该弱化。
