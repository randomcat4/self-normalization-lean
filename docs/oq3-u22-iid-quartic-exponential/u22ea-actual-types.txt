DECL Shao.OQ3.imaginary_real_exponential_quadratic_error
TYPE ∀ (b c : ℝ),
  ‖Complex.exp (↑b * Complex.I + ↑c) - (1 + ↑b * Complex.I - ↑b ^ 2 / 2 + ↑c)‖ ≤
    (Real.exp 1 + 4) * |b| ^ 3 + (Real.exp 1 + 2) * |c| * |b| + c ^ 2 * Real.exp |c|
AXIOMS [propext, Classical.choice, Quot.sound]
KIND theorem
