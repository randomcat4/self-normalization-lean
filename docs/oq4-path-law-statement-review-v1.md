## 全 h/z 延拓与零步

S_n(h,z) 只检验时间 1,…,n，未在时零杀死区间外起点。这与已选核在整个实轴的延拓、P^0(z)=δ_z 一致；源域 |z|≤h 内与严格离开闭区间的 τ 约定完全相同。

n=0 时，Path 0 是唯一空路径，有限空乘积是概率 law，S_0 是全集，终点 E_0=z。逐行测度等式因此应确实保留 δ_z，不应把它变成闭区间限制的 δ_z。

h<0、n≥1 时生存事件为空，与正步杀死核零行一致；n=0 仍保留空生存与 δ_z。h=0 时目标点零的原子保留；z=0 的源应用包括全零路径。任意 z 的扩展允许第一步进入闭目标区间，不额外约束初始位置。

## 逐行测度恒等式

冻结要求全部 n,h,z 的完整测度恒等式
\[
P^n(z)=\operatorname{map}(E_n(z,\cdot))

\]
这是未归一化的被杀终点 law，保留存活总质量。它没有降为仅总质量、矩相等或几乎处处起点相等。
