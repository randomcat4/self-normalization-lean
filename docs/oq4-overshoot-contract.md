# R6 三阶矩支付的积分接口冻结 v1

源：current/oq4/b01/proof01.md §6 R5–R6。依赖 frozen-finite-v1.md 的 F-R，不改写旧冻结版本。

令 (Ω,μ) 为任意有限测度空间。U:Ω→ℝ，μ-几乎处处 U≥0，U 与 U³ 都可积。定义

b_j = ∫ (j+1) max(U(ω)−j,0) dμ(ω)，j∈ℕ。

结论：
1. 每个被积函数都可积，b_j≥0；
2. 对全部 L，sum_{j<L} b_j ≤ 4(∫U dμ+∫U³ dμ)；
3. (b_j) 可求和，sum_{j≥0} b_j ≤同一右侧。

μ=0、U=0、原子、整数值、无界 U 全包含。不得加入四阶矩、U 有界或尾部连续性。有限测度是原概率测度的推广；原 U=|Y| 的一阶矩由有限二阶矩已有，不能把独立的一阶矩假设宣称原根新增限制。

这关闭 R6 从逐点有限支付到所有边界层的期望支付，仍不证明 O0、R2、R3、K/Kv 或 OQ4。禁止把后者作为本接口的隐含假设。
