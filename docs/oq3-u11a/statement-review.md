## 第三阶段：独立兼容性论证及逐项声明检查

### 目标一：任意有限前缀依赖的正预算均可同时满足

以下给出独立构造论证以判断签名可实现性；这不是尚不存在的Lean证明或构建记录。令p_J为已选长度J的有限前缀，S_J为其和，同时维护正数b_J。起点p₀为空，取

`b₀ = min(eps/2, F(0,p₀)/2)`。

空前缀合法，所以hF先合法给F(0,p₀)>0，故0<b₀≤eps/2<eps。递归取r_J=b_J/2，把p_J追加这一项成为p_{J+1}，再取

`b_{J+1} = min(b_J/2, F(J+1,p_{J+1})/2)`。

关键不变量为`S_J+b_J≤b₀`、b_J>0、p_J逐项正，且p_{J+1}严格延伸p_J。先由不变量得到

`S_{J+1}=S_J+b_J/2 < S_J+b_J ≤ b₀ < eps`。

此时才调用hF于p_{J+1}，取得其正预算并确保b_{J+1}>0。又有r_J+b_{J+1}≤b_J，故下一步不变量成立。这样对hF的每次使用都以前缀合法性独立建立为前提，没有先借未来总和来循环证明当前合法性。

一致的追加递归给一条r，且p_J(i)=r(i.val)，不是每个阶段另选一条序列。由b_{J+1}≤b_J/2得`r_J≤b₀·2^{−(J+1)}`，非负几何级数比较给真实Summable，且`Σ'J r_J≤b₀≤eps/2<eps`。对于任意固定J，同样从该步开始比较有`r_{J+k}≤b_J·2^{−(k+1)}`，于是整个无限尾满足

`Σ'k r(J+k) ≤ b_J ≤ F(J,p_J)/2 < F(J,p_J)`。

这同时覆盖全部J，包括J=0；严格界来自预算预留一半，而不把有限尾极限的≤误写为严格<。每一项r_J=b_J/2严格正。F可以在不同前缀任意不连续、不可测、快速趋零；递归仅消费当前合法有限前缀的严格正值，所以这些都不构成反例，也不需要新增正下界或连续性前提。

### 目标二：固定预算与自适应预算

取`G(J,past)=min(F(J,past),a(J))`。在每个合法前缀上hF和ha分别给两个数严格正，故G严格正。目标一给同一r及整个未来尾<G；由min≤两侧分别得到两个严格尾界。无需a可和、单调或有统一正下界；不只是每阶段控制一个下一项。签名中的结合顺序确实对每个J同时保留F与a的两项不等式。

### 目标三：先固定所有合法前缀的见证选择

把合法性记为`L(J,past):=(∀i,0<past i) ∧ Σ_i past_i<eps`。由hW可在每个满足L的前缀上选一个n满足W；在不合法前缀取0，从而得到对全部J/past定义的完整函数chooseN。其性质是对全部合法前缀成立，不只对将来某条r的前缀成立。经典选择或自然数最小见证都足以完成这一逻辑步骤，无需先存在最终r。

定义`F(J,past)=cap(J,past,chooseN(J,past))`。对任一合法前缀，先用选择函数的W性质，再用hcap得到F>0；非法前缀的cap不需正，也不会被hF合法门使用。然后应用目标一生成同一条r。其所有实际前缀都由全正、真实Summable和总质量<eps保证合法，因此全部实际见证W与cap尾界同时有效。chooseN的全域性质在选择最终r之前已固定；输入类型仅含有限前缀，预算不能借此读取未定未来尾。

签名明确要求hW对每个合法前缀存在见证、hcap对这些前缀的每个W见证为正，这些足够支持上述应用。没有把未证明的LLT见证当作定理内部结论，也没有对选择函数增加单调、趋于无穷或样本量增长要求。若下游需要n≥J、相位返回或误差条件，必须将其写入实际W并独立证明相应hW。本声明只给条件兼容性，不解决实际W/hcap的分析证明。
