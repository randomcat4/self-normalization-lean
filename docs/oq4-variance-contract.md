# K→Kv 精确有限标准化接口冻结 v1

源 b01/proof01.md §1：v∈[1/2,2] 下 Y/sqrt(v) 的标准化。禁止把该接口等同于未证的长时间 K/Kv。

1. 任意 n:ℕ（允许0）、a:Path n、σ>0、h≥0。令 a'=σ⁻¹ •a，H=h/σ。则对所有 k，prefixSum a' k=prefixSum a k/σ，energy a'=energy a/σ²；
   (∀k≤n, |prefixSum a' k|≤H) ↔ (∀k≤n, |prefixSum a k|≤h)。弱边界与零路径保留。不得以已有共同 crossing≥ 事件的补集替代该弱事件。
2. 对任意测度 μ、实随机变量 Y，若 Y、Y²、|Y|³ 可积，σ>0，∫Y=0、∫Y²=σ²，则 Z=Y/σ 的对应三者可积，∫Z=0、∫Z²=1、∫|Z|³=σ⁻³∫|Y|³。无需 μ 无原子，无需四阶矩或有界支持。
3. 若另有 σ≥1/2、∫|Y|³≤M，则 ∫|Z|³≤8M。该明确安全常数只用于共同矩界；不是最优常数主张。
4. 给定 v∈[1/2,2]，证明 σ=sqrt(v)>0、σ²=v、σ≥1/2，从而接口2/3可合法实例化，得到同一共同矩界8M。h>0时，N/(h/σ)²=v*N/h²，N/(h/σ)³=σ³*N/h³，N为任意自然数；保留精确等式，不只给渐近记号。

预计 Shao/OQ4/VarianceScaling.lean（可按需要拆为 PathScaling/MomentScaling，但只限 OQ4）。使用现有共同 path/energy定义；不得修改公共定义。允许直接复用 prefixSum_smul、energy_smul。所有原有分布/独立性搬运仍由公共FiniteIID提供；本模块不擅自改变共同接口。

语义风险：n=0不调用带0<n的absMax；正缩放确保双向不等式；若用σ⁻¹表示必须排除σ=0；μ无需概率化，积分线性需要显式可积；第3项中的M非负由非负三阶矩积分及其上界推出或可显式要求M≥0（冻结采用M≥0，以免语义不清）。全部根仍OPEN。
