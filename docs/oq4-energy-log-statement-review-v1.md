## 量词与真实对象

冻结稿取任意实数上的 Borel 概率测度 ν，要求 x² 和 |x|³ 对 ν 真实可积，原点二阶矩等于 1，并定义实际 β = ∫ |x|³ dν。再取 T≥0、M≥0、β≤M、|s|≤T，以及所有 h≥H(M,T)。这一量词顺序忠实表达共同三阶矩类上的统一性。

实际对象仍是闭截断 B_h = {|x|≤2h} 的 Z = ∫ exp(sx²/h²) 1_B_h dν，不是抽象满足某个误差前提的正数。冻结稿要求从 N0 导出实际 Z 的估计和正性，没有把它们改作新假设。

无需中心或 id 可积作为额外前提。单位原点二阶矩和三阶可积已足以内供 β≥1；这是原测度的矩关系，与倾斜后的均值无关。M<1 时实际矩类为空，不影响全称声明，也无需加入 M≥1 或 M>0。

## 阈值与归一化常数

冻结稿的显式选择为

C_Z(T) = 1/8 + T/2 + exp(4T) T²，

H(M,T) = 2(1 + M + T + C_Z(T) M)，

C_log(T) = C_Z(T) + 4T² + 4C_Z(T)²。

这些选择有效。H 只依赖 M,T，C_log 只依赖 T；没有将 β、ν、h、s 或 M 隐藏到误差系数中。

在全部声明范围内，h≥H 供应 h≥2 和 β≤M≤h。由 N0 的实际展开界可得

|Z−1| ≤ T/h² + C_Z(T) β/h³
       ≤ (T + C_Z(T) M)/h
       ≤ 1/2。

因此 1/2≤Z≤3/2，特别是 Z>0。对数结论适用于真实正的 Z，不依赖 Real.log 在非正数上的总函数约定。

## 对数误差系数核对

令 a=s/h²，r=Z−1−a，v=Z−1。N0 给出 |r|≤C_Z(T)β/h³，且上述阈值给出 |v|≤1/2。冻结稿所列实对数余项界 |log(1+v)−v|≤2v² 在该闭区间有效，对 v 的两种符号均适用。常数核对得到的支付项为

C_Z(T)β/h³ + 4T²/h⁴ + 4C_Z(T)²β²/h⁶。

其中 h≥1 与内部 β≥1 供应 h⁻⁴≤βh⁻³；β≤M≤h≤h³ 供应 β²h⁻⁶≤βh⁻³。因此精确得到冻结稿所写

|log Z−s/h²| ≤ C_log(T)β/h³。

系数中的两个 4 均安全，未漏掉 β² 项，也未以依赖 M 的系数替代源要求的 T-only 系数。阈值较源的“充分大 h”更明确而且安全，没有减弱共同矩类统一性。

## 端点、原子与范围

h=H 的弱边界、|s|=T、T=0、s=0 都被保留。s=0 时 Z 是闭截断质量，通常不等于 1，log Z 也不被设为 0；该误差仍由三阶尾支付。零原子和 ±2h 边界原子保留于闭截断，严格补集为 |x|>2h。原测度可含任意原子，也可无界，不需要额外四阶矩、指数矩、密度、对称性或非格点条件。
