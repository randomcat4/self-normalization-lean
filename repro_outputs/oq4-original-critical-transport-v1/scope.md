# 原始独立同分布空间的临界反例传输

本批连接已有乘积空间概率结果与原始样本过程。最终范围以精确源码、独立终审和服务器收据为准；本文不是验收结论。

SparseOriginalIIDTransport 保留固定稀疏律 P(0)=3/4、P(±2)=1/8，只要求正索引独立以及各坐标与该律的 IdentDistrib。原事件使用实际最大部分和和实际平方和；确定分母事件只把分母换成 sqrt(n)。有限事件等式对所有 n、所有实阈值成立，计数零与零能量的质量为 (3/4)^n。沿字面 n=(2m)^3、x=1/sqrt(2m)，两类实际 Brownian 相对概率分别趋 (1+exp(pi²/2))/2 和 exp(pi²/2)。

RademacherOriginalIIDTransport 针对固定 Rademacher 律，在任意原始样本空间的字面 x=c*n^(-1/6) 上传输整列临界相位、极限点集合和不收敛结论。极限点集合是 [1,exp(pi²/(4*c³))]。c=1 时，((j+1)^3) 子列趋 exp(pi²/4)，((j+2)^3-1) 子列趋 1。两者均为弱边界；未将立方数子列结论扩张为整列单极限。

RademacherOriginalStrictBoundary 在同一原始样本空间支付严格正前缀事件的有限原像和概率等式。沿 n=(j+2)^3、x=(j+2)/sqrt(n)，严格相对概率趋1，弱相对概率趋exp(pi²/4)，实际弱概率与严格概率之比趋exp(pi²/4)，两概率的对数差趋pi²/4；两类对数相对概率除以主速率j+2均趋0。严格事件在n=0采用空正前缀的真空约定。

两模块保留 X0 未用、几乎处处可测、非完备样本空间、独立样本/Brownian 宇宙及实际给定 Brownian 分母。不增加矩、空间完备性、连续分布或正能量假设，不声称新颖性，不改变 p54 或既有原子修复。全部原根组仍为 OPEN，已有局部闭合范围保留。此前已接受的渐近生产者只消费其接口并复用原有检查和审查证据。
