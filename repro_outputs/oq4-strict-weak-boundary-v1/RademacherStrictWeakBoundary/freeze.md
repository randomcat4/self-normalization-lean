# 一般尺度严格／闭边界商冻结

五个精确源码声明在证明前冻结：integerIndicator、ratio 两定义，boundary_gap、boundary_main、boundary_tendsto_iff 三定理。全部前导、完整类型及透明值固定；正文局部 have/let 允许，不增顶层声明或前提。无私有头授权。

实际概率为同一 Rademacher 有限乘积律的闭条带与正前缀严格条带之商。Nat floor/ceil gap 身份仅 h≥0；尺度假设正是 h→∞、n/h²→∞、n/h³最终有固定正上界。输出共同尾的真实正性、合法log分解，三种修正极限及完整整列趋值判别。不得假设尺度3收敛，不得对零概率前缀约消。

公共头没有布朗假设。证明内使用既有已合格 CanonicalBrownian 的具体过程及律，调用同一分母的弱、严格S4后在共同正尾相减；该旧证明资格复用，未新增外部公理。

本冻结只选 context221 的第一单元，排除 criticalRatio、两种算术子列、临界有理／无理分类及可选原空间搬运；后续须另行冻结。来源 spectrum01 §2/4；不作一般分布、一般OQ4原根闭合或新颖性声称。所有原根 OPEN。
