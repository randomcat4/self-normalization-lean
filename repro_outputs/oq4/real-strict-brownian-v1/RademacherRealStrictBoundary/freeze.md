# 正实数严格边界：负责人冻结

已完整阅读原 spectrum01.md 第1—4节、context212 的完整数学推导、实际被消费定义及接口。精确正式文本为 frozen-interface.lean.txt；仅1个定义与3个定理，定义完整值、量词、宇宙、可测空间及全部假设均已冻结。此时实现文件不存在。

范围为固定 Rademacher 律的有限正前缀事件。h>0 时 Nat.ceil h≥1，所以自然数前驱的 cast 等于实数 ceil 减1；整数绝对值 q 满足 q<h 当且仅当 q<Nat.ceil h，当且仅当 q≤Nat.ceil h−1。零前缀在非负闭边界内，故 N=0 保持全集。标准路径空间仅有 AE 整数前缀支持，不能声称任意实路径集合相等。原空间仅用已接受 AE iid 有限向量同分布，不增加完备性或点态可测性。非整数正边界上严格与弱事件 AE 相等，整数端点仍保留区别。

允许证明体内部 have/let，不准新增 top-level private/helper/instance 或改动冻结假设。全部 Lean 和递归公理门禁在指定服务器 CPU18–21 及 OQ4 单重命令锁下执行。复用旧模块成功对象与既有审计；不重编、重哈希或重审旧生产者。

本单元不声称一般严格临界相位渐近、概率正性或任何原根闭合。后续旧 S4_ALL 的严格上界入口在整数端点不满足，必须另证一般边界平移与误差控制。
